# ADR 0002: AES-256-GCM para segredos

- Status: aceito
- Data: 2026-09-22

## Contexto

Tokens e segredos de webhook nao podem permanecer em texto claro. O sistema precisa detectar adulteracao no conteudo cifrado.

## Decisao

Usar AES-256-GCM com nonce aleatorio por valor. A chave de 32 bytes e fornecida somente por `CREDENTIAL_MASTER_KEY` no ambiente de execucao e nao possui valor padrao.

## Consequencias

Backups de dados nao bastam para recuperar credenciais sem o secret manager. Rotacao de chave precisara de um processo explicito de recifragem.
